# Code of Conduct

## Our standard

MindBop is a community for players, developers, artists, designers, writers, testers, and curious people who want to build and play games together.

We expect everyone participating in the project to:

- Be respectful and constructive.
- Assume good intent while addressing problems directly.
- Welcome newcomers and help them learn.
- Give useful technical feedback without personal attacks.
- Respect different skill levels, backgrounds, opinions, and approaches.
- Keep discussions focused on the project and its users.
- Respect intellectual property and licensing requirements.
- Avoid harassment, discrimination, threats, hate speech, doxxing, sexual harassment, and deliberate disruption.

## Project spaces

These expectations apply to repository issues, pull requests, discussions, code reviews, community channels, game submissions, and other project spaces where MindBop participants interact.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, restrict participation, or take other reasonable action when behavior violates this code of conduct.

If you experience or witness unacceptable behavior, report it privately through the security/support contact documented in `SECURITY.md` or `SUPPORT.md` rather than escalating the situation publicly.

## Scope

This code of conduct is a community standard, not a legal contract. It is intended to make MindBop a productive, welcoming, and fun place to build.
