# Support

Need help with MindBop?

## Players

For gameplay problems, room issues, UI problems, or feature requests, open a GitHub issue with:

- Game name
- Device/browser
- What you expected
- What actually happened
- Steps to reproduce
- Screenshot or short recording when useful

For ideas that need discussion rather than a bug report, use GitHub Discussions when enabled or open a feature request.

## Developers

If you are building or publishing a game for MindBop, start with:

- `README.md`
- `CONTRIBUTING.md`
- `docs/game-publishing.md`
- `docs/architecture.md` when available

For security issues, follow `SECURITY.md` instead of opening a public issue.
