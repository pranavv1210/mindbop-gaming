# Accessibility

MindBop aims to make browser gaming usable by as many players as reasonably possible.

## Product goals

- Maintain readable text and sufficient contrast.
- Support keyboard navigation for platform UI.
- Provide visible focus states.
- Avoid relying on color alone to communicate important game state.
- Respect reduced-motion preferences where practical.
- Keep controls understandable on touch devices.
- Provide clear connection, error, and loading states.
- Avoid animations that prevent users from accessing essential controls.

## Game-specific accessibility

Different games have different interaction models. Game contributors should document known accessibility limitations and provide alternatives where practical.

If you encounter an accessibility barrier, please report it as an issue with the affected game, device/browser, steps to reproduce, and the experience that needs improvement.
